# Results by event: latest result per card, details in a modal

Applies to the **By event** grouping of the Results tab only. The **By meet** grouping is unchanged.

## Card

- Header unchanged: event, course, personal best (relays show the "relays never count" caption instead).
- The chart button is gone, and so is the inline chart on desktop. Desktop and mobile behave the same.
- The card shows one row: the newest result within the active filters (a season filter shows that season's newest). DQ, No Show and Scratched count as results and show their status.
- The row keeps its content (date · meet, round, badges, notes, time), but the meet name is plain text, not a link.
- Editors keep the pencil on the card. It opens the time entry sheet, not the modal.
- Tapping anywhere else on the card opens the event's modal. The card has a hover background, a pointer cursor and a focus ring, and is named "Show details: {event}" (`showDetailsNamed`, replacing `showChartNamed`).
- Desktop keeps the two-column grid.

## Modal

- Title: event and course, e.g. "50 Freestyle SCY".
- Under it: the personal best (relays: the "relays never count" caption instead).
- The interactive chart when the event has 2 or more points to chart. With one point, the chart's existing "One time so far: {time} on {date}" line. With none (only DQ, No Show or Scratched), the line "Not enough swims to chart yet". Relays have no chart.
- An "All results (N)" section with a chevron. It is collapsed by default (expanded for relays, which have nothing else to show) and collapses again each time the modal opens. It lists every result, newest first, with the same rows as the old card list: meet links, and a pencil per row for editors.
- Editing from the modal opens the time entry sheet over the modal. Closing the sheet returns to the modal, still open.
- A tap outside the modal, or the Close button at the bottom, closes it. Whether the modal is open is local state, not in the URL.

## Implementation notes

- Existing Modal and card styles are reused. No new visual design.
- Picking the latest result per event is a pure helper in `src/lib/`, with a unit test.
